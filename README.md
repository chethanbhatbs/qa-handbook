# The QA Handbook

36 chapters covering the topics every QA engineer needs, from test cases to testing AI agents.

Open `index.html` in a browser. It is one self-contained file.

| Level | Covers |
|---|---|
| Start here | Learning order and the goal: isolate a problem to the UI, API, backend or database |
| Beginner | SDLC and STLC, test plans and strategy, scenarios vs cases, test cases, bug lifecycle and reports, severity vs priority, types of testing, coverage and traceability, environments and feature flags |
| Intermediate | How web apps work, test design techniques, API testing, Postman, authentication and authorization, SQL, DevTools, web and mobile testing, logs, exploratory testing, Git and Linux |
| Advanced | Automation, locators and page objects, Playwright, CI and flaky tests, performance (k6, JMeter), security (OWASP), retries and idempotency, testing AI products and agents, observability, risk and sign-off, tools |

Facts were checked against official sources (ISTQB, MDN, RFCs, OWASP, vendor docs) on 14 Oct 2026.

`src/handbook.src.html` is the editable source. Diagrams use [rough.js](https://roughjs.com) and the Virgil font from [Excalidraw](https://github.com/excalidraw/excalidraw) (SIL Open Font License).
